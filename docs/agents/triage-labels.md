# Rótulos de triagem

| Papel da skill | Rótulo no GitHub | Uso |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Aguardando avaliação da manutenção. |
| `needs-info` | `needs-info` | Aguardando informações de quem abriu a Issue. |
| `ready-for-agent` | `ready-for-agent` | Especificação suficiente para implementação por um agente. |
| `ready-for-human` | `ready-for-human` | Exige implementação humana. |
| `wontfix` | `wontfix` | Sem intenção de implementar. |
